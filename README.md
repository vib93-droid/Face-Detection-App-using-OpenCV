# Face Detection App using OpenCV (Google Colab)

## 📌 Project Overview
This project detects human faces in an image using OpenCV and Haar Cascade classifiers.

The application allows users to upload an image in Google Colab, processes it, and highlights detected faces with bounding boxes.

---

## 🚀 Features
- Upload image directly in Google Colab
- Detect faces using Haar Cascade algorithm
- Draw rectangles around detected faces
- Display number of faces detected
- Simple and beginner-friendly computer vision project

---

## 🛠️ Technologies Used
- Python
- OpenCV
- Google Colab
- Matplotlib

---

## 📂 How It Works

1. User uploads an image
2. Image is read using OpenCV
3. Converted to grayscale
4. Haar Cascade classifier detects faces
5. Rectangles are drawn around faces
6. Output image is displayed
